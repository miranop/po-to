# po-to — Windows 98 風ポートフォリオ

[98.css](https://jdan.github.io/98.css/) と React (Vite) で作った、Windows 98 風のポートフォリオサイトです。
デスクトップのアイコンをダブルクリックすると、ドラッグで動かせる・重ねられるウィンドウが開きます。

## 機能

- 🖥️ ティール背景のデスクトップ＋ショートカットアイコン
- 🪟 クリックで最前面に来る、ドラッグ移動できるウィンドウ
- 🗂️ ウィンドウを重ねて複数同時に開ける
- 📊 スタートボタン・起動中アプリ・時計付きのタスクバー
- ➖ 最小化／復元（タスクバーから切り替え）
- 🔊 起動音（Web Audio API で合成したオリジナルのチャイム。著作権フリー）

## 起動音について

`src/sound.js` で Web Audio API を使い、起動音を**その場で合成**しています
（音源ファイルは使っていないので著作権の心配はありません）。
ブラウザの自動再生制限により、ページを開いた瞬間ではなく
**最初のクリック／キー操作のタイミングで一度だけ**鳴ります。
タスクバー右下のスピーカーアイコンをクリックすると、いつでも鳴らし直せます。
音色を変えたいときは `src/sound.js` の `chord`（音の高さ）を調整してください。

## 開発

```bash
npm install
npm run dev      # 開発サーバー（http://localhost:5173）
npm run build    # 本番ビルド（dist/ に出力）
npm run preview  # ビルド結果をプレビュー
```

## 内容（プロフィール・実績・これからやりたいこと）の編集

中身はすべて **`src/data/content.jsx`** にまとまっています。
このファイルの文章を書き換えるだけで、各ウィンドウの内容を差し替えられます。

- `windows` 配列 … デスクトップに並ぶ「プロフィール」「実績」「これからやりたいこと」
- `aboutWindow` … スタートメニューから開く「このサイトについて」

各項目の `icon`（絵文字）、`title`、`width`（初期幅）、`body`（中身の JSX）を編集してください。
新しいショートカットを増やしたいときは、`windows` 配列に項目を追加するだけです。

## GitHub Pages で公開する場合

`vite.config.js` の `base` を、リポジトリ名に合わせて設定してください
（例：`base: '/po-to/'`）。`npm run build` で生成される `dist/` を公開します。

## 構成

```
src/
  main.jsx              エントリーポイント（98.css を読み込み）
  App.jsx               ウィンドウ管理（開閉・重なり順・最小化・移動）
  styles.css            98.css に重ねる独自レイアウト
  data/content.jsx      ★ ここを編集して中身を差し替え
  components/
    Desktop.jsx         デスクトップ
    DesktopIcon.jsx     ショートカットアイコン
    Window.jsx          ドラッグ移動できるウィンドウ
    Taskbar.jsx         タスクバー＋スタートメニュー
```
